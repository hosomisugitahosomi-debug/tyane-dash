# 検証02：損益分岐スプレッドの早見表

> ⚠️ **これは試算であり結論ではない。** 勝敗数のみを入力とし、RR 1:1 を仮定している。
> ロジックの中身も実際の獲得値幅も使っていない。実測値が出たら作り直すこと。


目的：ローカルで平均値幅（pips）が出た瞬間に、当てはめるだけで合否が分かる状態にする。
実行：`scripts/breakeven.py`

## モデル
RR 1:1・時間決済（3分後に成行決済）を想定。

```
1トレードの期待値[pips] = (2p - 1) × G - C
  p = 勝率 / G = 平均値幅[pips] / C = 往復コスト[pips]（スプレッド + スリッページ + 手数料）

損益分岐に必要な値幅   G_min = C / (2p - 1)
コスト込みの実効勝率    p_eff = p - C / (2G)     ← 検証01の表にそのまま入る
```

## 結論

**判定基準はこれ1行**：
> 3分保有で、往復コストの **(1 / 2×余裕) 倍** の平均値幅が取れるか。

往復コスト1.5 pips と仮定した場合の必要値幅：
- **ポン円 18.2 pips** ／ ユロ円 37.7 pips ／ ビットドル 25.4 pips相当

**3分保有で18〜38 pips は、かなり高いハードルです。** 通常のボラティリティでは届かない可能性が高く、ここが計画全体の分水嶺になります。

### 順位が入れ替わった点
検証01ではビットドルのリターンが最大（+18.6%）でしたが、コスト耐性で見ると **ポン円が最も有利**です。理由は勝率が高く（64.3%）、必要勝率との余裕が大きいため。ユロ円は余裕が2.0ptしかなく、**コストに最も弱い**。

### ドル円は確定で除外
検証01で利益日不足、検証02で必要勝率に5.0pt足りず。**コストを引く前から利益目標に届きません。**
