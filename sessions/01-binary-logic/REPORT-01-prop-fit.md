# 検証01：手元の勝敗データは FundedElite の条件を満たすか

対象：`index.html` 内蔵の日別勝敗データ（2026-01-01〜06-10、4ペア、計2,906トレード）
実行：`scripts/prop_check.py`

## 前提（すべて仮定。未検証）
- **A1** バイナリーの1勝を +1R、1敗を -1R に読み替え（RR 1:1）
- **A2** 日内のトレード順序が不明なため、DDは日次終値ベース。**日中DDは過小評価**
- **A3** Daily Loss Limit = 3%（記事のInstantプランの値。他プランは未確認）
- **A4** **スプレッド・スリッページは未考慮**。以下はFXコストを引く前の上限値

判定基準：利益目標12% / 利益日3日以上 / 一貫性30%以下 / 最大DD10%以下

## 結論

### ✅ クリアできるもの
- **一貫性30%**：全ペアで最大12.2%。**大差でクリア**。合格後払いプラン（期待回収倍率13.58倍）の最大の懸念だったが問題なし
- **利益日3日**：ポン円19日・ビットドル9日・ユロ円6日。**十分**
- **最大DD10%**：日次ベースでは余裕（ただしA2の通り日中DDは未評価）
- **利益目標12%**：ポン円+16.8% / ユロ円+14.5% / ビットドル+18.6% で到達

### ⚠️ 問題点
1. **ドル円は不適格**。勝率54.5%で分岐点52.6%とほぼ差がなく、利益日は2日しか作れない。**除外候補**
2. **利益目標到達に約5.5ヶ月かかる**。上記リターンは全期間の数字。月次では+2.6〜3.4%程度
3. **同一銘柄リスク制限が最大のボトルネック**。1トレードあたりのリスクが **0.07〜0.17%** まで圧縮される。トレード回数が多いペアほど不利で、ビットドル（1日最大21回）が最も圧迫される

### 利益日を作るのに必要な日次勝率（導出）
1トレードのリスクを r、その日のトレード数を n、純益を net とすると
- 銘柄リスク制限：`n × r ≤ 1.5%`
- 利益日条件：`net × r ≥ 0.5%`
- 両立するには `net / n ≥ 1/3` → **その日の勝率 66.7% 以上**（+1%なら83.3%以上）
- 複数銘柄に分散すれば合計枠3%が使えるため **58.3% 以上**に緩和される

実データで条件を満たす日：ポン円64日/109日、ユロ円62日/115日、ビットドル59日/160日、ドル円48日/115日。
