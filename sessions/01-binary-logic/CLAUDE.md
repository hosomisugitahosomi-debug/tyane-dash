# セッション01: バイナリーロジックのFX転用検証

## 目的
現在バイナリーで使っているロジック（MQL化済み）を再精査し、
FXの実コスト（スプレッド・スリッページ）を乗せても利益が残るか判定する。

## スコープ
- やる：ロジックの再確認 / TICKデータの確認 / コスト込みの値幅検証 / プロップ要件との突き合わせ
- やらない：ダッシュボード（`index.html`）の改修

## 完了条件
1. ロジックのエントリー・エグジット条件が文章で明文化されている
2. 1トレードあたりの平均獲得値幅（pips）が数値で出ている
3. スプレッド＋スリッページを引いた後の期待値が出ている
4. プロップの利益目標・DD制限に対して合否の見通しが出ている

## このフォルダ固有のルール
- 数値は必ず「検証済み」か「仮定」かを明記する。仮定値には根拠を書く。
- バックテスト結果はサンプル数と期間を必ず併記する。

## 必要な入力（ユーザーから受け取る）
- [ ] MQLソース（.mq4 / .mq5）
- [ ] TICKデータ（またはその一部・仕様）
- [ ] note記事の本文（プロップ要件）
