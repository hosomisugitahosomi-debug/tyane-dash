# sessions/ の使い方

1セッション＝1目的。目的が変わったらフォルダを分ける。

## 手順
1. `cp -r sessions/_template sessions/<連番>-<短い名前>`
2. その中の `CLAUDE.md` に「目的・スコープ・固有ルール」を書く
3. 作業の決定事項と結果は `NOTES.md` に追記する

## ルールの優先順位
ルート `CLAUDE.md`（全体） < セッションフォルダの `CLAUDE.md`（そのフォルダ内で優先）
