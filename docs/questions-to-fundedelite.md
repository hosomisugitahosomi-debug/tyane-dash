# FundedElite サポートへの確認事項

用途：ロジックが規約に適合するか、および検証の前提値を確定させる。
優先度A＝これが不可なら計画そのものが変わる。B＝数値の前提。C＝運用の詰め。

---

## 優先度A：これが最重要（回答次第で計画が変わる）

### A-1. 短期売買の線引き
現行ロジックは **平均保有3〜5分・1日10〜20回程度・シグナルベースのEA** です。
- 最低保有時間3分を満たしていれば問題ありませんか？
- それとも「HFT・超短期スキャルピング」「機械的な超短期売買」に該当し、禁止対象になりますか？
- 該当を避けるための具体的な基準（平均保有時間、1日の最大取引回数など）があれば教えてください。

### A-2. Scalping Add-on の要否
上記の取引スタイルの場合、Scalping Add-on（最低保有30秒）は必要ですか？
不要であれば通常口座で問題ないという理解で合っていますか？

### A-3. 取扱銘柄
以下の銘柄は取引可能ですか？また、それぞれの平均スプレッドと取引手数料（往復）を教えてください。
- GBPJPY / EURJPY / USDJPY
- BTCUSD（仮想通貨）

## 優先度B：検証の前提値（数値を確定させたい）

### B-1. Daily Loss Limit
- 各プラン（LITE1/LITE2/リトライ付き/Instant/合格後払い）の Daily Loss Limit は何%ですか？
- 計算の基準は「前日終了時の残高」「初期残高」「有効証拠金(equity)」のどれですか？
- リセットのタイミングと、その基準となるサーバー時間を教えてください。

### B-2. 同一銘柄リスク制限（Daily Loss Limit の50%）
- SLを設定した時点でリスクとしてカウントされるとのことですが、**決済後にその枠は戻りますか？** それともその日は消費されたままですか？
- SLを設定せずにエントリーした場合、リスクはどう計算されますか？
- 同一銘柄で複数ポジションを同時保有する場合、合算で判定されますか？

### B-3. 最大DDの計算
- チャレンジ時とFunded口座で、Static / Trailing のどちらが適用されますか？
- Trailingの場合、基準は「残高の最高値」ですか、「含み益を含むエクイティの最高値」ですか？
- Trailingはどこで停止しますか（初期残高まで到達したら固定される等）？

### B-4. 利益日の判定
- 「1日+0.5%以上」は、決済済み損益の合計ですか？ 含み益は含まれますか？
- 基準となる残高は、その日の開始時点の残高ですか、初期残高ですか？

### B-5. 一貫性ルール（30%）
- 計算式を教えてください（最大利益日 ÷ 総利益、で合っていますか）。
- 判定対象の期間は、チャレンジ期間ですか、出金対象期間ですか？
- 「1トレードあたり」ではなく「1日あたり」で判定という理解で合っていますか？

## 優先度C：運用面

### C-1. EAの利用
- EAの使用に事前の申請や登録は必要ですか？
- 市販EAではなく自作EAですが、他の利用者と類似のロジックと判定されるリスクはありますか？

### C-2. 出金とDDリセット
- 合格後払い・Instantプランでは、出金時にトレーディングDDがリセットされるとのことですが、この認識で合っていますか？
- リセット後の基準額は、出金後の残高になりますか？

### C-3. ニュース・週末
- 経済指標発表前後にトレード制限はありますか（何分前〜何分後など）。
- 「週末保有なし」の設定にした場合、金曜の何時までに決済が必要ですか？
