## ロジック設計に直結する制約（最重要）

| 項目 | 内容 | 我々への影響 |
|---|---|---|
| **最低保有時間** | 通常口座 **3分** / Scalping Add-on付き **30秒** | 現行ロジックは3分判定。**FX転用時の下限がここ** |
| 超短期売買の禁止 | 最低保有時間を守っても「機械的な超短期売買」は別途禁止（HFT・超短期スキャルピング） | 3分固定・高頻度の機械売買は**グレー**。要確認 |
| 同一銘柄リスク制限 | Funded口座で同一銘柄に使える1日のリスクは **Daily Loss Limit の50%まで**。SL設定時点でカウント（利確しても消費される） | 例：Daily DD 3% → 同一銘柄 1日1.5%まで。1日の試行回数が制限される |
| 最低利益日 | **3日**必要。1ステップ系は**+1%/日**、2ステップ系・Instant・合格後払いは**+0.5%/日** | 1日あたりの利益率にノルマがある＝ロット設計に直結 |
| 一貫性ルール | 合格後払いは **30%**（1日に勝ちすぎると出金条件を満たしにくい） | 利益の偏りを抑える必要 |
| DDの種類 | LITE系チャレンジ = Static DD / ライブ口座 = **Trailing DD** | 同じ数値でも実質の厳しさが違う |

## 禁止行為
- HFT・超短期スキャルピング / レイテンシーアービトラージ / サーバースパム
- 両建て（同一口座内・他社プロップ・一般FX業者との間も含む）
- 口座共有・代行業者の利用 / Account Rolling（大量口座でのハイリスク運用）
- 1回のトレードで利益目標達成を狙うギャンブル取引（ニュース一発勝負）→ Soft Breach対象

## 推奨カスタマイズ（記事の最適解・全口座サイズ共通）
```
利益目標 12% / 最大DD 10% / Profit Split 80% / 出金間隔 21日 / レバレッジ 1:30 / 週末保有なし
```
- 例外：2ステップ+無料リトライは **Profit Split 60%**（リトライ後50%固定になるため）
- 例外：合格後払いは **利益目標 6%**
- 例外：インスタントは 最大DD 10% / Profit Split 95% / 一貫性あり
- 口座サイズは 5,000万より **2,000万** の方が期待回収倍率が高い

## 料金オプションの注意
オプションは**加算でなく乗算**。例：スキャルピング+40%、週末+10% → 1.4×1.1 = **+54%**。
→ 有利オプションは**1つ程度に絞る**方がコスパが良い。
