## ロジック設計に直結する制約

| 項目 | 内容 | 確認 |
|---|---|---|
| **最低保有時間** | **通常口座 3分 / スキャルピングアドオン付き 30秒**。利益・損失にかかわらず適用 | ✅ |
| 違反時の扱い | 最低保有時間を満たさない場合、**アナリストが利益配分額を減額（軽微な違反）**。即失格ではない | ✅ |
| **戦略リスク制限** | Funded口座で、同一取引日に**単一銘柄で日次損失限度額の50%を超えるリスクを取ることは禁止**。「リスク」と「損失」は別物で、利益が出た取引にもリスクは計上される | ✅ |
| **一貫性ルール** | **口座開設時（または前回の出金時）からの累計利益の30%まで**。1日で大きく勝って出金、ができない | ✅ |
| **最低利益日** | ライブ口座で**3日以上**。1日あたり+0.5%（2ステップ系・Instant・合格後払い）／+1%（1ステップ系） | ✅（+0.5%×3日）／△（+1%の区分） |
| DDの種類 | チャレンジは固定、合格後は変動（Trailing）になる | △ |
| 超短期売買の禁止 | 最低保有時間を守っても「機械的な超短期売買（HFT）」は別途禁止 | △ |

> ⚠️ 英語版FAQ（2026-05-20更新）には日本語版にない「ソフトブリーチ」の定義があり、
> スキャルピング制限内の単発事例が軽微な違反として口座リセット扱いになる場合がある。
> **日本語版FAQだけを見て判断しないこと。**

## 禁止行為（△ note記事のみ）
HFT・超短期スキャルピング / レイテンシーアービトラージ / サーバースパム /
両建て（他社・一般FX業者との間も含む）/ 口座共有・代行 / Account Rolling / 一発勝負のギャンブル取引

## プランと期待回収倍率（△ すべてnote記事の独自計算）
勝率50%・RR1:1のランダムウォーク前提の試算であり、公式の数値ではない。

| プラン | 期待回収倍率 | 利益日条件 |
|---|---|---|
| 合格後払い | 13.58倍（2000万口座） | +0.5%/日 × 3日 |
| 2ステップ + 無料リトライ | 6.48倍 | +0.5%/日 × 3日 |
| 1ステップ + 無料リトライ | 6倍超 | +1%/日 × 3日 |
| LITE 1ステップ | 5.51倍 | +1%/日 × 3日 |
| LITE 2ステップ | 5.49倍 | +0.5%/日 × 3日 |
| インスタント | 下位 | +0.5%/日 × 3日 |

推奨カスタマイズ（△）：利益目標12% / 最大DD10% / Profit Split 80% / 出金間隔21日 / レバレッジ1:30 / 週末保有なし
オプション料金は**加算でなく乗算**（例：+40%と+10% → 1.4×1.1 = +54%）（△）
