# 費用まとめ

1ドル≒150円で概算。**価格は変動するため購入前に公式で要確認。**

## 費用の構造
```
① 購入費（前払い型 or 合格後払い型）
② 取引コスト（スプレッド ＋ 手数料）
③ リセット費用（違反・失格したとき）
```

加算ではなく掛け算。例：+40%と+10% → 1.4×1.1＝**+54%**。
→ 有利オプションは1つ程度に絞る方がコスパが良い。

## ③ リセット費用（ライブ口座・最大3回）✅
| 回数 | 費用 |
|---|---|
| 1回目 | 当初チャレンジ費用（割引前・アドオン込み）の**40%**、最低$10 |
| 2回目 | 1回目の2倍 |
| 3回目 | 2回目の2倍 |

**口座が損益分岐点または利益状態のときのみ実行可。** 負けてからの逃げには使えない。

## スキャルピングアドオンは必要か → **不要**
| 選択肢 | 費用 | 効果 |
|---|---|---|
| アドオンを付ける | +40%（乗算・未確認） | 最低保有30秒 |
| **決済を3分20秒にずらす** | **0円** | 最低保有3分をクリア |

ロジックは3分保有のため、決済タイミングを後ろにずらすだけで同じ効果が無料で得られる。
アドオンが必要なのは「3分未満で決済したい」場合のみ。
検証02の結果からは保有時間を**延ばす**方向になる可能性が高く、なおさら不要。

※アドオンを付けても「機械的な超短期売買・ティックスキャルピング」の禁止は別途残る。
